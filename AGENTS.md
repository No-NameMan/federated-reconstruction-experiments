# Работа с FedRecon

- Работай из корня репозитория. Код симулятора находится в `src/fedrecon/`, команды и YAML в `scripts/` и `configs/`, проверки конфиденциальности в `research/privacy/`. Вложенный checkout курсовой служит историческим снимком.
- Версионируй код, конфигурации, команды и небольшие несекретные сводки. Сырые данные, веса, полные журналы и материалы для руководителя храни локально. Архивы и результаты опубликованных в проекте запусков сохраняй с их происхождением.
- Для нового прогона выделяй новый каталог в `runs/` или `results/raw/`. Записывай ревизию, команду, конфигурацию, seed, версии среды и идентификатор данных. Отделяй измеренные результаты, условия применимости и планы.
- При изменении проверяй затронутую команду воспроизведения. Перед коммитом просмотри staged diff и неотслеживаемые файлы. В публичный GitHub отправляй только явно выбранные файлы без секретов, персональных данных и закрытых материалов. Сохраняй историю Git.
- Технические решения принимай самостоятельно. Тему ВКР, научные обещания и обязательства перед руководителем согласовывай с пользователем.
